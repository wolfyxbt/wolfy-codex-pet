# wolfy

wolfy 是一只适用于 Codex 的 v2 动画宠物。它拥有完整的年轻灰狼身体，同时保留参考图片中辨识度很高的人类／动漫脸部特征。

## 形象特征

- 灰色四足狼身体、尖耳朵和粗大的无环纹尾巴
- 黄色围巾
- 光滑的暖棕色人类／动漫脸庞
- 长短不一的黑色短刘海和额头印记
- 巨大的椭圆形白眼睛、细小的线条鼻子和张开的粉色惊讶嘴巴
- 没有犬科口鼻、黑色狗鼻、毛茸茸的脸部面罩或普通狼脸

## 技术规格

- 精灵图尺寸：`1536 × 2288`
- 文件格式：支持透明通道的 RGBA WebP
- 动画结构：11 行，包括 9 种 Codex 标准动画状态和 16 个视线方向
- 鼠标悬停：播放 5 帧第一人称卡通动画——wolfy 保持原来的侧前方朝向，头胸朝画面左侧并略朝用户、臀部位于身体右后方；用户侧的手和粗鞭柄从画面下方近景伸出，鞭梢向远处收细并击中尾根旁的屁股；wolfy 露出明显疼痛表情、后半身缩起并向前弹开；无血迹或伤口
- 宠物配置：`pet.json` 使用 `spriteVersionNumber: 2`

## 文件说明

- `pet.json`：宠物名称、描述和精灵图配置
- `spritesheet.webp`：完整的 v2 动画精灵图
- `qa/`：最终动作总览、视线方向图、方向盲测结果、连续性报告、图集验证、独立视觉检查结果和动画预览
